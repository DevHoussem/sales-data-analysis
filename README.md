
# Sales Data Analytics

## Project Overview

A sales data analysis project using Python, Pandas, NumPy, MySQL, SQL and Power BI.

The objective is to explore and clean sales data, identify business trends, and create an interactive dashboard.

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- MySQL
- SQL
- Power BI

## Analysis Objectives

- Calculate total sales and profit.
- Analyze sales by category.
- Compare regional performance.
- Analyze monthly sales trends.
- Identify the top 10 subcategories.

## Installation

### 1. Clone the repository:

```bash
git clone https://github.com/DevHoussem/sales-data-analysis.git
cd sales-data-analysis
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 5. Add the dataset

Place `SuperStoreOrders.csv` in `data/raw/`.

### 6. Run the Python scripts

```bash
python src/data_exploration.py
python src/clean_data.py
python src/analyze_sales.py
python src/import_mysql.py
```
